Repositorio de infraestructura como código en Azure gestionada con Terragrunt. 

Contiene la estructura y configuraciones para organizar y desplegar módulos de Terraform por ambientes (Dev, QA, Prod), aplicando buenas prácticas de naming, reutilización y separación lógica de recursos. 

Su objetivo es simplificar el despliegue, la gestión de variables comunes y la integración con CI/CD para entornos consistentes y escalables en Azure.
